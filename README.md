# Adkart
🛒 E-Commerce Web Application
Ei repository-te ekti purnoango e-commerce web platform-er source code royeche. Eta diye user-ra product khuje kena-kata korte paren ebong seller-ra tader product ebong order manage korte paren.

✨ Mukhyo Boishishtyo (Key Features):
👤 User & Seller Authentication: Secure registration, login, logout, ebong profile management system.

🛍️ Shopping Cart & Checkout: Product cart-e add kora, quantity update kora, ebong seamless checkout & order placement.

📦 Order Management: User-der order history (my_orders.php), order cancellation, ebong admin/seller-der order tracking (seller_orders.php).

🏷️ Product Management: Seller-der jonno notun product add kora, update kora, ebong coupon management system.

🖼️ Media Handling: Product image upload ebong gallery integration.
